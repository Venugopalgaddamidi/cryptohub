# Cryptohub

A cryptocurrency tracking and portfolio management dashboard built with **React**, **Vite**, and the **CoinGecko API**.

## Features

- **Dashboard** – global market stats, trending coins, top gainers and losers
- **Markets** – searchable, sortable crypto market table with live prices
- **Coin Details** – price history chart, market data, and coin information
- **Trending** – discover the hottest coins on CoinGecko
- **Watchlist** – save coins and track their prices (local storage)
- **Portfolio** – track your holdings and calculate P&L (local storage)
- **Categories** – explore coins by market category
- **Exchanges** – browse crypto exchanges and volumes
- **Settings** – toggle light/dark theme and choose display currency

## Tech Stack

- React 19
- Vite
- React Router 7
- Recharts (price charts)
- Axios (API requests)
- CoinGecko REST API

## Getting Started

```bash
npm install
npm run dev
```
